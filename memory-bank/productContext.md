# Product Context

## Бизнес-контекст
Компания продаёт ткани на Ozon и Wildberries. Остатки приходят от нескольких поставщиков (Galtex, ТексДизайн, АртДизайн, ТДЛ, ЛогатексПРО, Традиции Текстиля и др.). Артикулы на маркетплейсе отличаются от артикулов поставщика — связь хранится в `mapping.xlsx`.

## Проблемы, которые решает продукт

### Парсер остатков (`/parser`)
- Загрузка файлов остатков от поставщиков (XLS/XLSX, XML)
- Применение пороговых значений и правил преобразования
- Генерация единых файлов `ozon-stocks.xlsx` и `wb-stocks.xlsx` для загрузки на маркетплейсы

### Обработка заказов (`/orders`)
- Получение FBS-заказов «Ожидает сборки» с Ozon и WB
- Сопоставление артикулов через mapping-файл
- Группировка по поставщикам для копирования списков на отгрузку
- Отдельные группы: постельное бельё (SHF/DC/PC), без сопоставления

### Генерация стикеров (`/stickers`)
- Планируется; сейчас заглушка

## Ключевые сущности
- **Mapping-файл** — 12 листов, колонка A = артикул маркетплейса, B/C = артикул поставщика
- **Пороги (thresholds)** — минимальные остатки по поставщику/материалу
- **Креды маркетплейсов** — Ozon Client-Id/Api-Key, WB API Token

## UX-принципы
- Русскоязычный интерфейс
- Сегментированная навигация в шапке
- Статусы операций с индикаторами (успех/ошибка/предупреждение)
- Копирование списков артикулов одной кнопкой
