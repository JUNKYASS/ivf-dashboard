# Project Brief: IVF Dashboard

## Название
**IVF Dashboard** — панель управления IVANOVOFABRIC для работы с остатками тканей и заказами маркетплейсов.

## Цель проекта
Веб-приложение, заменяющее консольные скрипты и ручные процессы операторов:
- парсинг остатков поставщиков и генерация файлов для Ozon/WB;
- сбор и группировка FBS-заказов с Ozon и Wildberries;
- генерация этикеток Ozon/WB 58×40 с артикулом.

## Пользователи
Операторы склада / менеджеры, работающие с маркетплейсами Ozon и Wildberries.

## Ключевые страницы

| Роут | Страница | Статус |
|------|----------|--------|
| `/parser` | Парсер остатков | Реализовано |
| `/orders` | Обработка заказов | Реализовано |
| `/stickers` | Генерация стикеров | Этикетки 58×40 + артикул МП |

## Архитектура
Monorepo (npm workspaces):
- `backend/` — Express + TypeScript API
- `frontend/` — React + Vite UI
- `mapping.xlsx` — соответствие артикулов маркетплейса и поставщика
- Docker + nginx для продакшн-деплоя
