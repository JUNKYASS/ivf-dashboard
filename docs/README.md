# Документация IVF Dashboard

Живая документация проекта. Исходные ТЗ хранятся в `specs/` как архив.

## Структура

```
docs/
├── README.md           # Этот файл — оглавление
├── architecture.md     # (TODO) Общая схема системы
├── api.md              # (TODO) Полный список API
├── features/           # Документация по страницам
│   ├── parser.md       # (TODO)
│   ├── orders.md       # (TODO)
│   └── stickers.md     # Генерация этикеток 58×40
├── decisions/          # ADR — архитектурные решения
└── specs/              # Архив исходных ТЗ
    ├── parser-spec-v1.md
    └── orders-spec-v1.md
```

## Слои документации

| Слой | Где | Обновляется? |
|------|-----|--------------|
| Исходные ТЗ | `docs/specs/` | Нет (архив) |
| Живая документация | `docs/features/`, `docs/api.md` | Да, при изменении кода |
| Контекст для AI | `memory-bank/` | Да, при задачах |
| Быстрый старт | `README.md` (корень) | При изменении деплоя/запуска |

## Правило обновления
При изменении роутов, API, страниц или бизнес-логики — обновлять соответствующий файл в `docs/` и `memory-bank/techContext.md`.
